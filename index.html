Features

Also in Cove

  • Restore tabs, selections and scroll positions
  • Agent-suggested tasks
  • Quick Action for commands, tasks and skills
  • Automatic language detection in untitled tabs
  • Find unsaved text with literal search
  • Highlight embedded languages and code fences
  • Shebang and modeline detection
  • ⌘F in terminals and chats
  • ⌘-click paths in output
  • Install dependencies from the tree
  • Drag executable scripts into Tasks
  • Inline git blame
  • Ask Assistant about selected code
  • Image viewer
  • cove --wait as your $EDITOR
  • Editorconfig support
  • Use your project’s linters and formatters
  • Drop tasks and skills into any pane
  • Multiple cursors
  • No analytics
