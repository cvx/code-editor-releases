Features

Also in Cove

  • Sessions and shells survive a restart
  • Agent-suggested tasks
  • Typo-tolerant Quick Open
  • Unsaved buffers in search
  • Search hits survive edits
  • Cross-language highlighting
  • Shebang and modeline detection
  • ⌘F in terminals and chats
  • ⌘-click paths in output
  • Install dependencies from the tree
  • Extensive drag and drop
  • Inline git blame
  • License detection
  • Image viewer
  • cove --wait as your $EDITOR
  • Editorconfig support
  • Linters and formatters
  • Liquid Glass throughout
  • Multiple cursors
  • Highlight matching brackets
  • No analytics
